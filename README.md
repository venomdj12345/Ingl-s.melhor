# 🎨 Método das 3 Cores – Inglês Melhor

Site interativo para aprender a **ler e pronunciar inglês** de forma visual e simples usando apenas três cores de caneta + áudio de IA (Web Speech API).

## 🚀 Como usar

1. Abra o arquivo `index.html` no navegador (Chrome, Edge, Safari ou Firefox).
2. Navegue pelas páginas:
   - **Início** → Visão geral + áudio rápido
   - **O Método** → Explicação completa das 3 categorias
   - **Tabelas** → Referência rápida com botões de áudio
   - **Exemplos** → Frases e textos já coloridos
   - **Exercícios** → Prática + quiz interativo

## 🎨 As 3 Cores

| Cor | Significado | Exemplos |
|-----|-------------|----------|
| 🔵 **Azul** | Vogais neutras / curtas (incluindo schwa) | cat, sit, the, banana |
| 🔴 **Vermelho** | Letras mudas (não se pronunciam) | cake, know, write, night |
| 🟢 **Verde** | Vogais longas (a vogal “fala o próprio nome”) | name, time, home, cute |

## 🔊 Áudio

O site usa a **Web Speech API** nativa do navegador.  
Não precisa de internet na maioria dos casos e não exige cadastro.

## 💡 Dica de prática

1. Pegue um texto curto em inglês  
2. Marque com as 3 cores  
3. Leia prestando atenção só na cor  
4. Confirme a pronúncia com o botão 🔊
